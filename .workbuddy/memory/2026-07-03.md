## 修复发表论文页面空白问题
- 根因：`.fade-in-section` 默认 `opacity: 0`，需要 site.js 的 IntersectionObserver 添加 `.visible` 类才能显示
- 用户浏览器追踪防护阻止了 JS 正常执行，导致内容一直处于透明状态
- 修复方案：采用标准 "no-js/js" 渐进增强模式
  - `_layouts/default.html`: `<html>` 添加 `class="no-js"`
  - `_includes/head.html`: JS 可用时立即替换 `no-js` → `js`
  - `_sass/utilities/_animations.scss`: 默认 `opacity: 1`，仅 `.js` 环境下才应用 `opacity: 0` + 动画
- 这样无论 JS 是否可用，内容都能正常显示
- 已本地 commit，git push 因认证问题再次失败，需用户手动推送
